# Uni_Courses_only_classwork

This repository contains coursework files for university learning activities.

## Repository contents

- `1_vlog.py` — A simple Python script that demonstrates Big O notation examples.
- `Alpha_earth_model.ipynb` — Notebook project exploring land-surface instability as a landslide-risk signal in Western Rwanda.
- `recommender_systems_exercise.ipynb` — Notebook exercise for building a content-based recommender system.

## Running the Python script

From the repository root:

```bash
python 1_vlog.py
```

## Working with notebooks

Open the `.ipynb` files with Jupyter Notebook, JupyterLab, or Google Colab.
